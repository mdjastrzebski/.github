👋 Hi, I'm Maciej, a React Native developer at [Callstack](https://callstack.com/), based in Wrocław, Poland. I work on open source in the React Native ecosystem, both as part of my job and in my spare time.

🛠️ **What I maintain**
- [React Native Testing Library](https://github.com/callstack/react-native-testing-library) and [Test Renderer](https://github.com/mdjastrzebski/test-renderer): the most widely used testing solution for React Native
- [Reassure](https://github.com/callstack/reassure): performance regression testing for React Native and React DOM, built on top of RNTL/RTL
- [React Native Plain Text](https://github.com/mdjastrzebski/react-native-plain-text): a high-performance replacement for the RN Text component
